# Building Clockwork

Run `python3 tools/clockwork/build.py packs/clockwork` from the repository root.
Python's standard library and the shared `tools/pack_art.py` writer generate the
entire manifest deterministically. Only that data is used at runtime.

The upper train shares a tooth module and opposing pitch speeds; the open rims
are winding contours, so the lower mechanism shows through their centres. The
near balance wheel and bridge use a different projection scale during camera
approach. The camera has no filesystem or graphics authority of its own: all of
this is existing group translation and scaling.

Validate with the shipped renderer's `check` and `render` commands. Check the full
default cycle, all Camera/Finish choices, and Lively pace at the intended display
size. Theme colors should be checked against both a light and a dark palette.
The runtime flash guard remains unchanged.
